3개 프로젝트 연계 구조

ai-library-team1
사용자용 웹 서비스 (Spring Boot + Thymeleaf).
도서 검색(키워드/벡터/하이브리드/RAG), 도서관 챗봇, 리뷰를 제공.
⇄ 검색 · RAG 질의
book_embeddings
도서 임베딩 배치 서버.
리뷰를 RabbitMQ로 수신해 벡터를 생성/저장하고 스케줄러로 정기 배치 처리.
⇅ MCP 도구 호출
ai-library-mcp-server
정보나루(국립중앙도서관) Open API를 MCP 도구로 노출.
실시간 도서 정보, 인기 대출 도서, 도서관 소장/대출 가능 여부 등을 AI에게 제공.

사용자가 챗봇에 질문하면, team1의 AI 에이전트가 book_embeddings의 벡터 검색 결과와 mcp-server의 실시간 도서관 정보를 함께 활용해 답변을 생성합니다. 다음 장에서 하나의 질문이 실제로 어떤 순서로 처리되는지 자세히 보겠습니다.
