검색 기능 ② — 하이브리드 · AI 추천(RAG)

하이브리드 검색
키워드 매칭 점수와 벡터 유사도 점수를 RRF(Reciprocal Rank Fusion)로 결합해 상위 100권 후보를 뽑습니다.
정확도와 의미 검색을 절충한 방식입니다.
AI 추천 (RAG)
하이브리드 후보 중 RRF 점수 0.02 이상만 남겨 상위 5권으로 재랭크합니다.
5권을 컨텍스트로 LLM에 전달하면, 질문 맥락에 맞는 책과 추천 이유를 함께 생성합니다.
후보 100권 → RRF ≥ 0.02 → 최종 5권
동일 질문은 시맨틱 캐시로 즉시 응답
