Request Flow

하나의 질문이 처리되는 과정

1
질문 입력
웹 챗봇 또는 텔레그램에서 자연어로 질문을 입력합니다.
2
임베딩 변환 · 캐시 확인
team1이 질문을 BGE-M3로 임베딩하고, 동일한 질문이면 시맨틱 캐시에서 즉시 응답합니다.
3
하이브리드 검색 📦 book_embeddings
키워드+벡터 점수를 RRF로 결합해 book_embeddings가 미리 채워둔 pgvector 데이터에서 후보 100권을 조회합니다.
4
재랭크
RRF 점수 0.02 이상인 후보만 남겨 상위 5권으로 압축합니다.
5
프롬프트 구성
5권의 제목·저자·내용 일부·평점·리뷰 요약을 컨텍스트로 담아 프롬프트를 만듭니다.
6
LLM 호출 🔌 mcp-server
LLM이 답변을 만들다가 필요하면 MCP Tool로 mcp-server에 실시간 정보(대출 가능 도서관, 인기 도서 등)를 요청합니다.
7
추천 선별
LLM이 맥락에 맞는 최대 5권을 고르고, 각 책마다 추천 이유를 함께 생성합니다.
8
응답 반환 · 캐시 저장
도서 상세 정보를 조인해 사용자에게 응답하고, 결과를 캐시에 저장해 다음 동일 질문에 재사용합니다.
